## 平均分与平均向量并不相同

设目标t和每条参考u_i均为单位向量，μ=mean(u_i)：

- 逐条余弦平均：`A=mean(cos(t,u_i))=t·μ`。
- 当前宿主：`B=cos(t,normalize(μ))=A/||μ||`。
- 时长加权逐条平均：`C=sum(w_i*cos(t,u_i))/sum(w_i)`。

B会按每个人的参考均值模长重新缩放，参考一致性不同会影响缩放，甚至可能改变人物间排名。本轮完整参考均值模长：
- 长崎爽世：0.829586。
- 椎名立希：0.851641。
- 高松灯：0.844828。

因此不能因为质心法0.744比等权平均0.617大，就说准确率更高。三种方法在本目标上都分出了爽世；时长加权比普通平均的本次差距更大，也不足以证明它整体更准确。

## 采样与验收边界

- 各5条且每人5个不同chunk；各人原登记参考均保留。三条baseline的PCM与原登记相同、复提向量余弦为1，原登记片尾截断不被静默扩展。
- 爽世候选池来自上一轮已评分实验，本轮按“baseline+其他chunk按时间最早可用候选”固定选5条，排除chunk0近邻同措辞样本；不是完全盲测。灯/立希清单在本轮打分前按初始身份、动作和边界选定，未根据目标得分挑选。
- 每条来源文件SHA、初始event、视频SHA、checkpoint SHA均核对。15条参考初始Understanding v1时已经具名；无目标/参考重叠，无重复完整PCM，不使用Refine后补名作身份依据。
- 30次本地CAM++ CPU调用全部completed，30份输出均为有限、L2归一化192维向量。使用官方固定实现及checkpoint，16k mono PCM16，与宿主downmix一致；无VAD、降噪、人声分离、变速或响度处理。
- 首次调用约2.36秒，其余约20–45ms。本次空载离线计时不代表服务并发性能。实验超时120秒、CPU线程6，生产配置未变。
- 单个已知目标只能证明此次排名和分离变化，无法估计整集准确率或确定最优聚合策略。相似度不是身份概率。
- 本次只写本目录实验成果。没有向正式声纹库登记、改speaker、改数据库、重启服务、重解析、commit或push。人物条目中的references已能承载多条声音参考，生产聚合策略尚未因本实验修改。
