## 时长对照的含义

对每条参考固定取开头1500ms，与完整片段分别提向量，截取规则在评分前写入 manifest；没有滑窗挑最高分。九组可比较样本中 **7组完整更高、2组完整更低**，原1500ms baseline 两列相同。普通协商4.0秒从首1.5秒的0.555984降至完整的0.500743，因此分数并不随长度单调增加。

“首1.5秒”不保证同样的有效说话时长，可能含停顿、气口或不完整音节。5.2秒低落样本的来源台词仅“そう、羽丘……”，不能把文件时长直接当作有效语音量；真实听感以试听页为准。

## 证据与限制

- 情绪/状态来自既有动作、表情和对话描述，尚未独立人工试听标注。该实验同时改变台词、场景、语音内容和背景，不能把分数变化完全归因于情绪。
- 候选采集的 `source_content_version` 是最终快照版本2/3；身份核验实际使用 `initial_understanding_source` 和 `initial_event`，逐一验证最初Understanding v1时已经具名爽世，未依赖后来的声音比对补名。
- 保留原视频、初始来源快照、checkpoint SHA和encoder revision；目标、baseline PCM与已登记数据一致，baseline重提向量与登记向量余弦为1.0。
- 同真实宿主使用ffmpeg直接从原视频downmix至16k mono PCM16；无VAD、降噪、人声分离、响度归一化或变速。20次模型调用均成功，输出均为有限、归一化192维向量。
- 本次仅将实验调用超时设为120秒，为首次加载留余量；没有重试，没有修改生产30秒配置。模型首次调用约2355ms，后续成功调用约17–35ms，不能将该空载实验耗时与服务并发统计直接等同。
- 音频保留是用户要求收集/试听的实验成果，不改变生产登记临时音频清理语义。

固定实验清单：[manifest.json](manifest.json)；完整向量及PCM：[embeddings.json](run1/embeddings.json)；分数：[results.json](run1/results.json)；本地模型调用记录：[model-calls.json](run1/model-calls.json)。

```sh
.venv/bin/python -u engine/experiment/campplus/20261017-soyo-emotion/run.py \
  --output engine/experiment/campplus/20261017-soyo-emotion/run2
```

输出目录必须全新，脚本拒绝覆盖已有实验。所有参考与目标边界在manifest中固定；manifest SHA写入结果。实验目录被Git忽略，本轮只维护本地实验产物，无commit/push。
