## 输入与排除

24 个 chunk、378 条 ASR cue 全部计入：拆成 436 个不重叠短窗，另有 3 个 holdout，共 439 个向量；226 个参与拟合。长 cue 等分为不超过 3 秒的窗；没有把 ASR 匿名 speaker_id 或 Understanding 人名作为约束。一个 cue 即使被切窗也不保证单人，ASR 时间可能含两人的连续声音。

排除计数（可能一窗有多个原因）：`{"shorter_than_1500_ms": 181, "holdout_related_cue": 2, "op_range": 12, "silence_rms_below_minus50_dbfs": 9, "ed_range": 19, "holdout": 3}`。短于 1.5 秒、已标 OP/ED、低于 −50dBFS、重叠 cue、重复 PCM、holdout 相关 cue 不参与拟合或代表源。其余窗仍编码、分配和展示，不能把该分配解释成通过质量门禁。音乐范围来自保存的场景／歌词人工标记；RMS 只筛低能量／可能静音，二者都不是语音／音乐或多人检测器。

两个经典台词区间及与它们重叠的完整 ASR cue、重复音源在拟合、K 选择和代表源选择中均留出。3 个 holdout 包括同一爽世台词的 1.3 秒与 1.0 秒边界变体；不是 3 句独立真值。

## 算法与 K 扫描

使用 SciPy 1.15.3 `kmeans2`，输入 L2 单位向量，普通欧氏 K-means，**不是 spherical K-means**。不 whitening、不 PCA、不归一化簇中心。K=2…12，5 组 seeds×每组10 starts，++ 初始化、每次100轮；每组取 SSE 最低，五组胜者中 SSE 最低者作为该 K 的最终模型。K 由五组 cosine silhouette 中位数最高选择，完全并列取小 K；不读取人物名或 holdout 得分。当前选择 **K=2，seed=3002**，是此范围内几何指标的选择，不能当作已证明的人物数量。

所有分配与 holdout 预测使用原 K-means 中心的最近欧氏平方距离；中心 cosine 另列诊断，未用于改写预测。每个来源报告5组对齐后的归属次数、同簇至多10条独立 cue 近邻的平均 cosine、次近中心减本簇的欧氏平方距离差。它们不是身份概率；5/5 仅表示同数据的随机初始化稳定性，不是泛化验证。

本机 NumPy matmul 出现浮点状态告警；没有仅依靠 clip 掩盖。原始点积全有限且有界，与非BLAS `einsum(optimize=False)`最大差 1.55e-15；直接欧氏平方差与保存距离最大差 1.28e-15；55个组胜者的中心与最终标签均值最大残差 0。数值断言和告警原文见JSON。
