## 最新系列详情页要求

- 首页点击系列进入独立页面，路由为 `/series/:seriesId`；取代首页按需展开选集的交互。
- 顶部使用系列大图，展示系列名称与介绍；按照 2026-10-11 的纠正，介绍复用用户已有的短简介 `description` 与背景正文 `importantExtraData`。短简介为空但有背景时照常展示，保留正文和图片，长文可展开；不编造内容或要求重新填写。
- 继续观看复用已有持久化观看进度；下方展示该系列的集数与视频，保留进入实际播放页的路径。
- 品牌使用 Seekino，沿用薄荷绿以及现有明暗主题。
- 参考截图的布局与信息层级，不据此虚构评分、语言或收藏功能。

明确设计指示与实现验证记录见 [系列详情页设计确认](../../series-detail-approved.md)。

## 最新播放页要求

- 顶部保留 Seekino 品牌、功能入口和账号区；具体视频播放页面不将任何顶部功能 tab 标记为当前页。
- 顶部导航下优先呈现宽幅播放画面。
- 右侧对话区域可打开，按标注作为侧边对话框呈现。
- 播放画面下方，左侧承载标题、集数与简介等信息，右侧展示后续几集。
- 参考布局与信息层级，继续使用 Seekino 自身的色调、品牌和已有功能。

后续实现以最新纠正意见为准；本目录仅保存参考证据，不替换已有设计文档或素材。`docs/ui-design/` 依照项目已有配置作为本地设计工作区被 Git 忽略，本次未更改该配置。
