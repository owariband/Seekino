# Seekino · Provisional Brand Spec

> 采集与制定日期：2026-09-14
> 资产来源：Seekino 仓库、用户本轮明确要求、仓库内 MyGO 样例视频与解析产物
> 资产完整度：设计阶段临时规范；待三方向选定后形成正式 v1

## 核心资产

### 名称与标识

- 产品名统一写作 `Seekino`，不拆成 `Ani VAG`，不使用全大写。
- 当前仓库没有既有官方 Logo。方向稿使用不带图形臆造的临时字标 `Seekino`，辅以克制的字母 `A` 印章；它只用于判断整体品牌气质，不视为正式商标。
- 禁止使用机器人头像、播放三角形、胶片卷盘等通用 AI／视频图标充当品牌 Logo。

### 产品 UI 与内容素材

- 当前不存在 Seekino 既有 UI；本轮三方向稿即首批 UI 视觉资产。
- 演示内容来自仓库真实样例：`BanG Dream! It’s MyGO!!!!!` 第 7 集。
- 核心检索画面：`assets/frame-candidates/ep07-1258.jpg`，对应 20:56–20:59 的《春日影》质问片段。
- 辅助画面：`ep07-1184.jpg`、`ep07-0908.jpg`、`ep07-0864.jpg`、`ep07-0566.jpg`。
- 图片仅作为本地产品原型中的真实内容证据，不把动画画面误称为 Seekino 自有品牌资产。

## 色板

色彩母题是“雨后青瓷与夜色湖面”：青绿色来自用户指定，同时用低饱和与微暖中性色保留文艺、清新的纸感，避免荧光科技绿。

### 共用品牌色

- Primary / 雨后青：`#238C78`
- Primary Strong / 深青：`#146756`
- Primary Soft / 薄荷雾：`#D9EEE8`
- Fresh Accent / 新芽：`#7DB8A7`
- Warm Counterpoint / 书页米：`#E9E2D4`

### 日间模式

- Canvas：`#F4F7F2`
- Surface：`#FBFCF8`
- Surface Strong：`#FFFFFF`
- Ink：`#17312B`
- Muted：`#64756F`
- Hairline：`#DCE4DE`

### 夜间模式

- Canvas：`#0C1613`
- Surface：`#111E1A`
- Surface Strong：`#172723`
- Ink：`#EAF2EE`
- Muted：`#93A7A0`
- Hairline：`#2A3B35`
- 夜间主色提升明度至 `#62C5AF`，避免把日间颜色机械反相。

## 字型

- 中文正文：`Avenir Next`, `PingFang SC`, `Microsoft YaHei`, sans-serif。
- 文艺标题：`Baskerville`, `Songti SC`, `STSong`, serif。
- 时间戳与工程信息：`SFMono-Regular`, `Menlo`, monospace，仅用于短标签和数据。
- 正文最小 14px；主要阅读文本 15–17px；所有可点击目标至少 44×44px。
- 中文不使用伪斜体；引用通过宋体、字重或底色表达。

## 签名细节

- 把“时间证据”设计成贯穿界面的细青线／书签线，而不是普通进度条。
- 关键帧像被夹在一本检索札记中：图像是主角，UI 退后，证据文字保持可核验。
- 青绿色主要出现在关键动作、当前时间、选中结果和焦点状态，不大面积铺满背景。

## 禁区

- 不使用紫蓝霓虹、全屏渐变、磨砂玻璃堆叠和千篇一律的 AI SaaS 暗色风。
- 不使用 emoji、装饰性统计卡、无意义图标阵列或虚构用户数据。
- 不把低置信度结果伪装成确定答案；视觉上保留“候选”“证据”“需复核”的产品语义。
- 不让圆角卡片成为唯一结构；优先使用留白、细线、排印与图像比例组织层级。

## 气质关键词

干净、清新、文艺、安静可信、带一点电影札记感。
