# 导演稿 · Seekino 像素鲸鲨 · 动作短片

1920×1080 · 30fps · 18.8s（565 帧）· 暗色终端舞台 `#0c1412` · 像素缩放 20×（一格像素 = 20px）

形式来自内容：Seekino 是「边看边问」的视频检索助手，所以这只鲸鲨的每个动作都对应产品里的一个状态。片子按「醒来 → 看你 → 帮你找 → 赶时间 → 找到 → 再看你」一条线串起来，主角从头到尾只有这一只，不切镜，状态之间都是连续动作。

色板只用 `brand-spec.md` 里的颜色。字标用 Seekino 网页同款 Inter 750 字重（`assets/fonts/inter-wordmark-750.woff2`，SIL OFL），「i」的点用白色，和网页 header 一致。

## 能量骨架（18s）

| 段位 | 时间 | 能量 | 内容 |
|---|---|---|---|
| ① 开场 | 0–2.8s | 低 | 睡觉，飘 Z：悬念「它醒来要干嘛」 |
| ② 主角立传 | 2.8–8.1s | 低中 | 起身 → 走 → 转身正对屏幕，左右看，眨眼，小跳 |
| ③ 功能爬升 | 8.1–13.5s | 中 → 高 | 加载中（找东西）→ 冲刺跑到右边急刹 |
| ④ 收场 | 13.5–18s | 峰值后落定 | 转身正对屏幕，字标和 slogan 落下，hold |

## 音频 cue（SFX + BGM 双轨）

SFX 全部用 8-bit 方波 / 三角波 / 噪声现场合成，和像素画同一个时代感；时间点直接从引擎帧上的 `cue` 字段读出来，所以和画面逐帧对齐。BGM 用 `bgm-tech.mp3`，低通 4kHz、音量 0.65（这首母带偏轻，0.65 时峰值比 SFX 低约 8 dB），入 0.3s 淡入、出 1.5s 淡出；SFX 高通 800Hz、音量 1.0，amix `normalize=0`。

| cue | 画面 | 声音 |
|---|---|---|
| z | 每个 Z 冒出来 | 低三角波上滑，极轻 |
| wake | 起身 | 两音上行 |
| step | 走路脚着地 | 很短的噪声 tick，压低音量，每两步一个 |
| turn | 开始转身 | 短方波 blip |
| blink | 眨眼 | 极短高音 |
| hop | 小跳 | 方波上滑 |
| dot | 加载点亮起 | 三音依次升高 |
| dash | 起跑 | 噪声 whoosh |
| skid | 急刹 | 噪声下滑 |
| logo | 字标落下 | 方波和弦 + 低音 |
