# Seekino 系列详情页 · 设计确认

确认日期：2026-10-10。用户已明确要求本轮修改与参考素材备份；下列指示已实现，并完成自动化测试和本机浏览器验证，供用户验收。

参考：[用户原始标注图](references/2026-10-10/06-series-detail-annotations.png)（源文件 `codex-clipboard-DGdC3D.png`）。

## 已确认指示

- 首页点击系列进入独立系列详情页，路由 `/series/:seriesId`。本要求取代此前首页按需展开选集的方案。
- 页面顶部为系列大图，结合系列名称、用户提供的简介，以及开始或继续观看入口。
- 介绍使用用户已有的短简介 `description` 和背景正文 `importantExtraData`；两者都有时一起展示。短简介为空不能判定为没有介绍。背景保留 Markdown 标题、段落、图片及原有 JSON / `seriesBible` 兼容；长正文默认预览，可展开或收起。观看进度复用现有持久化记录，继续观看回到对应视频和位置。
- 大图与简介区域下方，列出该系列具体集数和视频，并能进入现有播放页。
- 使用 Seekino 品牌，沿用现有薄荷绿配色、明暗主题和功能入口；不照搬参考中的评分、语言、收藏等没有真实功能或数据支持的内容。

## 已验证的验收点

- 首页系列卡片进入对应系列详情页；直接访问详情页路由也能读取该系列，不依赖首页展开状态。
- 顶部大图、名称与介绍对应同一系列；只有短简介和背景正文都为空才显示介绍空态，封面缺失使用现有回退，不生成假数据。
- 有有效观看进度时可继续到该系列对应视频和保存的位置；没有进度时提供可播放视频的开始入口，不覆盖已有进度。
- 下方按集数展示真实视频，标明已有播放状态，点击后进入正确的播放路由。
- 桌面与移动端均能完整查看简介、续播入口与选集；明暗主题和顶部品牌保持一致。

本确认只更新本轮系列详情页方向；其他历史设计文档保留原样。

2026-10-11 用户纠正：“为什么是没有简介？我们不是有背景介绍吗？”已确认 `mygo` 的短简介为空，但背景正文已有 12,342 个字符。详情页应复用这份资料，不能要求用户重新填写。正文在详情页只读展示，资料库仍负责编辑。短正文完整显示；实际高度超过 240 px 才提供渐隐预览与展开按钮，尺寸或图片加载变化时重新判断。

- 首页、App 路由、系列详情、播放页与播放器相关测试共 87 项通过；TypeScript 检查和生产构建通过。构建仍提示既有的大于 500 kB 的资源包，本轮未调整打包策略。
