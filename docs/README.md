# Seekino 项目介绍

Seekino 把视频整理成可以搜索的个人资料库。上传视频并完成解析后，输入一句对白、一段画面描述或一张参考图，即可找到对应片段。结果附带集数、时间范围和原片入口。

看课程时，可以先浏览整集大纲，再跳到讲解某个概念的地方。在播放器里追问时，回答可以引用当前画面和资料库里的其他片段。找剪辑素材时，本机 MCP 接口也能返回带出处的片段，供剪辑工具读取。
