# Seekino 宣传 PV 设计与制作方案

记录日期：2026-10-09；更新日期：2026-10-10。用途：为后续 Seekino 原创宣传 PV 提供可复用的创意、音乐分析与制作依据，并记录《AIZO》重剪能力验证。

核心方向是用《AIZO》推动一次“找回记忆中的画面”的产品叙事：记忆碎片 → 描述画面 → 线索收拢 → 看清证据 → 命中并播放。音乐的爆发落在观众确认“真的找到它了”的瞬间。综合《明日方舟》2020 感谢庆典 PV、联动活动《月行水上》PV 与用户提供的 P3R OP 视频，提炼排印、图形运动、空间转场和信息层次，让 Seekino 的检索与时间证据成为视觉主体。

## 已确认的需求

- 宣传对象：Seekino 项目，用于后续产品宣传。
- 参考方式：用户明确选择“只参考它的视觉风格，另做原创画面”。参考片用于分析与风格提炼。
- 参考范围：用户先后指定三份视频，均纳入后续设计依据；没有指定必须以其中某一支为主。
- 当前 BGM 方向：King Gnu《AIZO》。用户认可用其能量变化承载产品的寻找与命中过程，具体选段、剪辑落点及收尾方式仍需验证。
- 已认可的叙事主题：**你记得的那一幕，值得被找回来。** 用同一个画面的开头碎片与高潮完整播放形成呼应，让产品体验产生情绪回报。
- 原创宣传片交付：设计文档与素材初步分析。正式 Seekino 成片时长、音乐片段、发布版本与发布渠道尚未确定。
- 另行确认的能力验证：以《月行水上》为主素材，可取用另外两支视频，按《AIZO》全曲重剪，分三段制作；先交付 Part 1，用户审看后再调整后两段。
- 活动卡也属于有效参考：用户明确无需避开角色／活动介绍卡，后续希望模仿其页面形式。验证样片可以使用原片中的卡片；Seekino 正式片以原创图形和真实产品信息重做。
- 正式主宣传片当前建议约 60–75 秒；这是执行建议，尚未锁定时长。此前“先做 30 秒方向样片”的建议由本次主片方案更新。具体文案、色彩应用、音乐时间点和输出规格仍需在制作中确认。

## 产品叙事与事实依据

已认可主题：**你记得的那一幕，值得被找回来。** 产品字标旁的短句可沿用“找回你记得的画面”，最终措辞随演示案例精修。

一支短 PV 集中展示一条完整体验：观众只记得人物、动作或场景，却不知道它在哪支视频、哪一分钟；通过自然语言描述发起寻找，候选逐渐收拢，展示关键帧与时间证据，最后跳回原视频播放。将最有冲击力的音乐落点交给“找到并播放”的结果。

同一个目标画面在开头短暂、局部地出现，作为尚未找回的记忆；高潮时再以完整、可辨认的片段出现，并与真实检索结果对应。观众由此感受到寻找过程的回报，也能理解 Seekino 的用途。全片围绕一个主要成功案例组织，其他画面和图形为这条线索服务。

制作首先选择一个真实检索成功、找到后有情绪回报的案例：保留实际查询、命中结果、关键帧、时间码与对应原片。先确定“找到的那一幕”，再反向安排开头的记忆碎片、输入过程和高潮。表达检索的图形动画应与真实界面、真实证据衔接；剪短等待时保留可识别的镜头省略，避免让观众误解为未经验证的即时响应。

产品能力以制作时的运行版本为准。当前定位参考[项目说明](../../../README.md)和[前端说明](../../../web/README.md)：事件级视频检索、自然语言查询、集数与时间段、关键帧证据、原视频跳转播放。正式录制前，选定一个实际成功的查询，核对输入、结果和播放位置。

品牌沿用已确认的“青瓷札记”。[方向确认](../../ui-design/direction-approved.md)与[品牌规范](../../ui-design/brand-spec.md)提供视觉依据；这些历史设计文件中的功能完成状态不作为当前产品事实。上述品牌资料位于本地忽略目录，本文保留制作必需的色彩与名称约束，便于后续独立使用。

宣传文案只覆盖演示版本已验证的能力。检索等待若被剪短，应通过明确的镜头省略表达；“秒出结果”“准确率”“完全离线”等承诺需要另有对应证据。

## Seekino 的视觉方案建议

将“时间证据线”作为贯穿全片的图形：开场它连接尚未定位的记忆碎片；查询时沿线展开候选；命中时停在真实片段时间，并引向开头画面的完整播放；结尾收回产品字标旁。每次图形变化都对应观众能理解的产品动作。

| 元素 | 建议用法 |
| --- | --- |
| 品牌名称 | 统一写作 `Seekino`；片尾可先使用产品字标，正式图形 Logo 以制作时确认的资产为准 |
| 主色 | 雨后青 `#238C78`、深青 `#146756`；命中、选中与时间证据使用青色 |
| 浅色场景 | 纸白 `#F4F7F2`、深色文字 `#17312B`，适合查询、证据与结果说明 |
| 深色场景 | 墨绿黑 `#0C1613`、浅色文字 `#EAF2EE`，青色强调可用 `#62C5AF` |
| 排印 | 中文主信息清晰简洁；大标题、短标签与等宽时间码构成层级；一镜优先只传达一个动作 |
| 图形 | 时间线、关键帧裁切、检索关键词、选区与证据连线；用窄窗口、几何框口和短标题连接场景 |
| 运动 | 分层平移、窗口穿行、局部放大、斜向遮罩和尺度转换；结果揭示时动作落稳，保证阅读 |

参考片的强烈黑白对比可以保留；品牌强调色优先使用青绿色。UI 展示继承现有产品气质，片头与转场可以增加速度与张力。复杂角色动作、完整三维场景与逐帧动画需要独立素材或专项制作，首版优先用原创图形、产品画面和分层合成完成。

## AIZO 的节奏分析与踩点规则

本次将音频解码为 22.05 kHz 单声道分析信号，按约 10 毫秒步长计算分频段的正向对数频谱通量，再用自相关检查重复周期。全频信号的主要候选约为 **189.98 BPM 与 94.99 BPM**；周期拟合约 189.99 BPM，对应约 **0.3158 秒**的脉冲间隔。

190 与 95 存在倍速／半速计拍歧义。频谱突变可能来自鼓、吉他或人声，尚不能据此确定每小节第一拍、鼓种、拍号、主歌或副歌边界。使用 0.316 秒或 0.632 秒的节奏层级作为编排起点，正式落点需逐段校正。

踩点需要同时考虑三个层次：

1. **段落变化**：较长的能量变化与乐句边界决定铺垫、展开和收束，先选适合叙事的连续音乐区间。
2. **主要重音**：承载命中揭示、主标题、场景转换等重要事件；动画最清楚或冲击最强的时刻对齐重音。
3. **细分脉冲**：承载关键词、短标签、线条和局部运动，使同一镜头内部也有节奏。

剪辑原则是：**动势跟随音乐，信息照顾观众。** 产品界面可连续停留约 3–4 秒，以选中框、标题、局部放大或结果卡进场响应重音；具体持留时间根据文字长度与审片反馈调整。密集切镜集中用于期待积累和动作高潮，关键查询、时间码与结果进入稳定阅读段。用于正式成片的时间点以音频源文件的绝对秒数记录，再转换为成片相对时间与帧号，避免累计四舍五入漂移。

后续音乐标记建议包含：`source_time_seconds`、`event_type`、`strength`、`confidence`、`review_status`。其中 `event_type` 区分脉冲、候选重音与段落边界；算法候选与已复核落点分别记录。若对接 HyperFrames 工作流，以当时实际要求的 `audiomap.json` 契约为准。

## 主宣传片的分镜与音乐安排

当前按约 60–75 秒、16:9 的主宣传片规划，以一次完整的成功检索体验支撑音乐张力。以下沿用《AIZO》开头的源时间做结构草案；在未裁切音乐的草案中，源时间与成片相对时间一致。区间来自现有瞬态和能量分析，尚未通过听辨确认乐句；这里只标铺垫、强起、缓冲等剪辑用途，不认定主歌或副歌边界。

| AIZO 源时间草案 | 画面与动作 | 文案草案 | 音乐与产品叙事的关系 |
| --- | --- | --- | --- |
| 约 0–10 秒：想起一幕 | 人物、地点、动作以记忆碎片短暂出现，目标画面只露出局部；最后留下寻找的问题 | 这一幕，在哪里？ | 用少量元素、停顿和短促切换建立期待，让观众产生寻找的欲望 |
| 约 10–26 秒：把记忆说出来 | 功能标题带入真实 Seekino 界面，输入一句自然语言描述，完成后触发检索 | 描述画面 | 强拍落在界面揭示、输入完成和操作动作上；查询文字保持可读 |
| 约 26–42 秒：线索收拢 | 视频资料库、候选关键帧、结果卡逐步展开，真实主结果进入画面中心 | 找到片段 | 图形和窗口的快速运动积累期待，关键结果出现后落稳；时间码提供可核验的落点 |
| 约 42–54 秒：看清证据 | 稳定展示视频标题、命中关键帧与时间码，让观众理解结果，并准备进入播放 | 找到它发生的那一秒 | 利用相对缓和的能量区间，给产品信息与真实操作留出观察时间 |
| 约 54 秒后至选定收尾：找到并播放 | 点击结果跳回原视频；开头闪过的画面完整出现，再收束到 Seekino 字标与实际入口 | 回到原片；你记得的那一幕，值得被找回来 | 再次爆发承接找到目标的回报，随后为品牌和行动提示安排自然的音乐收尾 |

正式收尾需要单独设计：根据听辨选择可结束的音乐位置，并为命中画面的完整播放、字标和入口留够时间。重剪验证 Part 1 的 76.933333 秒是续接点，不能直接当作正式主片已经确定的结尾。若调整音乐区间，需重算源时间、成片时间和帧号映射。

正式文案以选定演示案例与版本为准。查询、关键帧和时间码必须来自同一次可重现演示；检索对象使用原创或另行确认的演示视频。正式 Seekino 宣传片使用新制作的图形和真实产品素材；参考 PV 原画面的直接取用仅属于另行授权的重剪验证。

### 三张功能卡的具体用法

| 功能卡 | 主视觉与次要信息 | 与实际产品画面的衔接 |
| --- | --- | --- |
| 描述画面 | 一句真实查询为主，配对应画面局部；标题明确当前动作 | 卡片带入输入界面，查询完成后展示实际检索操作 |
| 找到片段 | 命中的关键帧为主，突出真实时间码，视频标题作为次要信息 | 图形运动收拢到真实结果卡，留出稳定阅读段 |
| 回到原片 | 结果卡或片段窗口为主，保留对应片段信息 | 窗口展开成播放器，接上开头画面的完整片段 |

每张卡采用“一个主视觉、一个大标题、一组次要信息”的层级。参考《月行水上》的立绘布局、斜切色块和大字结构，将内容替换为 Seekino 的关键帧、功能名称与时间证据；进场响应重音，落稳后供观众阅读。三张卡分别服务对应叙事节点，后续可复用于版本发布页和宣传图。更完整的元素映射见文末“活动卡向 Seekino 页面转译”。

## 素材准备与制作流程

制作前先锁定有情绪回报的真实成功案例，再整理可用产品字标、目标版本 UI、完整查询录屏、对应结果与原片位置，以及所需原创背景或图形。目标片段既提供开头的记忆碎片，也提供高潮的完整播放；三张功能卡围绕同一案例制作。原创插画或复杂场景可以另行生成与制作；文字和时间标签在合成层排版，方便修改并保证清晰。

1. **锁定 brief 与演示案例**：沿已认可主题选定一次真实成功检索，核对目标画面和结果证据，再明确目标观众、版本、渠道、时长和音乐范围。
2. **复核音乐**：确认乐句、主要重音与收尾位置，输出带来源时间的节奏标记；处理所选区间的进出音。
3. **制作静态关键帧**：验证开头碎片与高潮完整画面的呼应，制作三张功能卡、检索结果和片尾，核对风格一致性与阅读层级。
4. **建立动态样片**：使用 HyperFrames 编排可定位的时间线，将音乐标记映射到镜头、文字和图形的动作峰值；镜头可独立调整。
5. **替换与完善素材**：放入真实演示录屏、核对结果、补充原创图形，处理局部运动、转场、音效与音量。
6. **输出与检查**：导出审片 MP4，带音乐连续观看，同时静音检查产品叙事；修正节奏、可读性与事实问题后输出正式版本。

今后复用时保留色板、排印层级、时间证据线、标题与尾卡组件；新音乐重新分析，新版本重新验证演示，新卖点重新组织叙事。模板服务于一致性，镜头内容与切换时间随具体片子变化。

每支 PV 使用独立制作目录，包含 brief、素材、音乐标记、分镜、可编辑 HyperFrames 工程与输出文件。音乐标记与镜头都保留源时间，便于换段与复核。下表用于后续原创制作；重剪能力验证的实际交付另见文末。

| 交付物 | 用途 |

## 验收标准

- 音乐与画面：主要动作峰值对应选定重音；播放开头、中段、结尾均无逐渐累积的偏移；进出音自然，没有截断尾音或明显爆音。
- 节奏：观众能感到铺垫、揭示与收束；关键文案与检索结果有稳定阅读时间。
- 叙事回报：开头的目标画面与高潮播放可明确对应；音乐爆发承接“找到并播放”，观众能理解寻找的起因和结果。
- 功能卡：三张卡的主视觉、标题和次要信息层级明确；进场后留出稳定阅读段，每张卡都与同一案例的真实操作或证据衔接。
- 风格：时间证据线、青瓷色与排印统一；图形变化支持产品叙事，原创镜头能独立成立。
- 产品：观众看完能复述“描述画面 → 找到片段 → 跳回原视频”；演示案例真实，集数、时间码、关键帧与播放内容一致。
- 画质：最终分辨率下文字清晰、关键内容不出画；无缺素材、意外黑帧、音画不同步或明显缩放失真。
- 可维护性：工程可重新打开和渲染；素材路径、音乐裁切范围、输出规格与版本信息可追溯。

## 正式制作前需要确定的事项

1. 宣传范围：沿已认可的“找回记忆中的一幕”主题，确定目标观众、所展示的产品版本与实际发布入口。
2. 目标时长与渠道：当前建议约 60–75 秒主片，最终时长尚未锁定；横屏与竖屏按渠道分别构图。
3. 音乐执行：《AIZO》为当前 BGM 方向；具体起止区间、段落听辨、音乐收尾及是否加入旁白仍待确定。
4. 演示内容：目标版本、查询问题、真实结果、录屏与原片位置。
5. 视觉资产：正式字标、可用原创素材、片尾入口；复杂动画的制作范围另行确定。

后续可直接以本文件开始制作 brief：先补齐上述事项，再将分镜中的占位时间替换为实际音乐落点，进入关键帧和动态样片制作。

### 活动卡向 Seekino 页面转译

| 原片形式 | Seekino 可用内容 | 动作与阅读安排 |
| --- | --- | --- |
| 大角色立绘与角色名 | 真实检索结果关键帧与能力名称 | 主视觉在重音出现，标题随后稳定，避免标题与关键帧同时持续移动 |
| 英文大字与彩色斜切区域 | 中文功能标题、短英文索引、版本编号 | 用斜切区域引导视线；沿用 Seekino 青瓷色，不直接复制联动品牌标识 |
| 星级、职业及角色编号的信息区 | 视频标题、片段时间码、资料库或演示编号 | 只使用实际存在的信息，不以装饰性数值暗示未经验证的能力 |
| NEW OPERATORS／活动标题卡 | 新版本、新功能或专题内容揭示 | 先用短标题建立层级，再给具体信息留阅读时间；实测后决定持留时长 |
| 角色卡之后接实机展示 | 能力卡之后接真实操作录屏 | 卡片说明看点，后续画面展示同一能力的实际结果 |

活动卡的关键是“一个主视觉、一个主标题、一组次要信息”及其进场顺序。正式制作先做可替换内容的静态版式，再设计约 6–12 帧的进场和稳定阅读段；具体时长以文案长度及目标音乐为准。

### AE 与 Blender 的适用范围

现阶段先验证选镜、音乐结构和剪辑节奏。AE 适合后续制作可编辑的活动卡、文字层、遮罩、图层合成与细化转场；Blender 适合确实需要原创三维场景、摄像机或几何运动的镜头。无需为了完成现有素材重剪先配置两者。

用户提供的 [ae-blender-frame-recreation](https://github.com/EGSECDA/ae-blender-frame-recreation) 是分镜重建工作流与脚本辅助库，采用 AE JSX 和 Blender 脚本，不是直接输入整支 PV 就能自动复刻的成片生成器。迁移时可复用本次 EDL、源素材时间、音乐标记和活动卡设计；仍需实际运行 AE／Blender 并检查渲染结果。
