# 3. 改造方案

在既有上传配置及 V2 任务快照中显式选择 anime。Understanding 记录人物脸部、手势、转折前后可见的差别与对应台词。动画 Refine 只用现有文本核对，保留视觉证据。原有 Timeline 负责保存和索引。这轮限定为提示词改动，代表帧用返回区间回看，后续单独评价持久化关键帧。

在 MCP 的工具发现说明中提示扩大查询、查看邻近证据、核对多个候选的原片。为完整覆盖提供逐页浏览，按本机租户、系列和发布版本回源。可选出镜姓名用于角色选镜。授权、任务版本和单页体积仍由服务核验。[#35](https://github.com/owariband/Seekino/pull/35) 另行维护跨事件合并的角色出场区间。

# 4. 对照实验

使用本地 MyGO 五集独立测试库。先保留原查询、旧事件和版本，保持 DeepSeek Flash、思考档、720p 和 3 fps。通过正式重解析入口创建一个整集新版本，再用相同系列、相同 top_k、相同原句回放。额外记录用户的剪辑需求「戴眼镜的爱音被课程难住，咬紧牙、双拳攥在脸边」。不向模型或检索提供集数、时间、原台词。全量浏览覆盖另记，不能替代语义排名验收。

# 5. 试点与取舍

试点为一个 24 分钟左右的正片，其他四集提供真实干扰项。由 MCP 客户端读出证据与原片，检查返回表情是否成立、笑容边界是否仍提前。记录耗时、失败重试及未满足条件。本地试点不能代表全部动画或云端部署。
