# 1. 问题与现状

观看页片内查找当前只返回台词与画面文字。[文字查找设计](watch-text-find-trd.md)与 [文字接口](../../../server/service/media.py) 已有当前视频的访问控制和毫秒跳转。MyGO 第 2 集的原片在 12:56.500 显示千早爱音坐在沙发上看手机，14:07.500 显示她背着吉他包在路上走。两个镜头均有出镜标注，字幕均未提及她。本需求允许用户找到这些画面，也可关闭画面结果。

分支为 `feat/watch-visual-find`，目标分支为 `dev`，[开发 PR #120](https://github.com/owariband/Seekino/pull/120)。沿用 [#105](https://github.com/owariband/Seekino/pull/105) 的查找组件和本地已验收的紧凑样式。独立人物工具 [#35](https://github.com/owariband/Seekino/pull/35) 面向跨素材的角色枚举；本次从当前视频的正式事件读取浏览器所需的小范围数据。

# 2. 影响因素、假设与评价指标

| 场景 | 原行为 | 通过条件 |
| --- | --- | --- |
| 只搜出镜人物 | 只查文字原文 | 繁简、姓名短写可命中已标记的镜头；画外提及只落入文字结果 |
| 人物加动作或自然语言 | 当前面板没有画面描述 | 查找已标注动作，语义候选受到当前视频范围和出镜条件约束 |
| 开关与连续输入 | 无此选择 | 默认开启，浏览器记住选择；关闭立即撤销画面结果与在途查询；文字可独立使用 |
| 权限与版本 | 文字读取已发布解析 | 私有视频、其他集及失效数据不得混入；索引缺失仍可搜索已有文字和画面标注 |

# 3. 改造方案与建模

作用对象为已获准观看的单个 `tenantId + videoId`。前端沿用一个输入框与上一处、下一处。打开时独立获取文字；开启画面时读取一次本集视觉事件。输入姓名在已缓存的 `visiblePersons` 上做繁简和空白归一。只有可见人物能支持出镜。相同或被包含的出镜区间只显示一次，独立镜头保留自己的位置。

`GET /api/videos/visual-timeline?tenantId=…&videoId=…` 返回 `{ready,knownPersons?,cues:[{startMs,endMs,kind,description,visiblePersons}]}`。本集人物名册用于识别查询中的名字。数据来自最新已发布的 Timeline。画面描述优先在本集匹配；非纯人名输入暂停后调用 `POST /api/videos/visual-search`，正文为 `{tenantId,videoId,query}`，应答返回 `{ready,cues}`。台词、屏幕文字及本地出镜命中按时间排列，再按相关度列出最多五处「相关画面」。展示前用出镜名单核对查询指定的人物。复用既有事件检索与回源核验，在 SQL 范围选择阶段限制 Video，网络查询沿用访问校验和模型额度。没有独立查询改写步骤。关闭期间不读取画面接口。切集、关闭、改词应中止过期请求。

# 4. 对照实验与结果分析

在同一集输入「愛　音」，Chrome 显示 248 处去重后的出镜标注，语义接口调用为零。关闭「画面」后，这些结果消失。刷新再搜索时，画面接口请求数仍为零。「高　松 灯」仍停在 11:20.820 的台词和 22:00.000 的片尾文字。已知画外人物、迟到的请求、索引未就绪和切集均有回归用例。

# 5. 试点验证与方案取舍

隔离试点按冻结的模型合同恢复 E02 的 24 个 Chunk、559 个事件，逐组核对事件 ID 与已发布内容。使用本机 Qwen3-Embedding-0.6B 和 Elasticsearch，搜「肩背乐器包在街道上走」，首条为 14:05.166–14:10.833 的吉他包镜头。搜「房间里低头刷手机」，第二条为 12:54.833–12:58.500 的爱音镜头。无关查询也会召回相似候选，界面把它们标为「相关画面」。本机四次 API 请求耗时 645–2940 毫秒，包含本轮首个请求。

12:54.833 的起点只看得到房间。画面结果改用半开区间的整数毫秒中点，显示时间与实际落点一致，悬停可看来源区间。原片在 12:56.666 显示爱音看手机，14:07.999 显示她和同伴背包走路。文字结果仍使用起点。

# 6. 结果验收与闭环

独立开发分支构建和本地预览均通过桌面 Chrome 与 390 像素手机视口验收，覆盖快捷键唤起、人物与同义场景搜索、关闭后刷新、时间戳跳转。后端验证在调用模型前限制授权视频，覆盖解析失效和查询中撤回分享。其他剧集的出镜标注完整度及生产效果待验。[原片与浏览器验收记录](../../report/server/evidence/watch-visual-find-local-20261112.json) · [工作台](../../dev/workbench.html)
