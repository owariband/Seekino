# 1. 问题与现状

2026-11-25。0.2.20 的空资料库首页在导入说明外画了一张卡片，又给 Kino 加了底色、边框和两排胶片孔。真正可以操作的地方是文件拖放、选择视频、模型设置和 Kino 本身。分支 `fix/desktop-empty-library-layout`（[PR #192](https://github.com/owariband/Seekino/pull/192)）接在 [#191](https://github.com/owariband/Seekino/pull/191) 后。

# 2. 影响因素、假设与评价指标

两层装饰框给普通插画增加了控件的外观。以原来的空库同尺寸截图作基线，验收时应只看到标题、可用操作和站在地面上的 Kino。小窗口也要看得到 Kino。

# 3. 改造方案与建模

修改 BrowserPane 的空状态布局，直接使用 Kino 自带的地面与动画。保留全窗口拖放及现有导入和设置事件。资料库有系列时继续显示原来的首页。

# 4. 对照实验与结果分析

用空库在暗色宽窗口、浅色和窄窗口检查图形边缘及按钮裁切，实测选片、拖放、配置模型和减少动态效果。

# 5. 试点验证与方案取舍

在 Apple Silicon Mac 上从签名包启动。两平台共用这段 QML，Windows 单独核对压缩包内的改动。

# 6. 结果验收与闭环

2026-11-25，0.2.21 已在 Apple Silicon Mac 安装并重新打开原资料库。用最终签名包在隔离空库实测 1080 × 700 点暗色，以及 640 × 440 点浅色并展开侧栏。两层装饰背景与胶片孔均已移除，窄窗中 Kino 位于标题上方。点击视频按钮能打开选片框，拖入文件能进入导入队列，辅助入口能打开模型设置。Kino 点击有反馈，启用减少动态效果后静止。既有首页与翻译测试 3 项通过。Windows x64 包核对了相同 QML，真机显示仍待验收。
