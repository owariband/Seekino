# 3. 改造方案与建模

1. 协调器按解析任务维护已提交块、窗口的成员位和可领取的具体 ID，恢复时用轻量持久状态初始化。第九个不同块提交可开放下一批。窗口位首次齐全可领取 refine。一次 refine 提交新放行的块直接进入 index。三条队列可混跑。每个进程在当前租约下用轻量快照维护这些信息，成功的数据库领取与提交更新具体 ID。仅在数据库提交成功后向下游发布，旧版本、延迟通知及重复通知不能绕过租约、暂停、到期、ASR、声纹或各阶段容量。
2. 分发按 ID 校验并领取。内存可先排除已满的阶段，数据库继续序列化实时与后台共享的容量。对已知就绪的任务先尝试立即取父行，遇忙时在 MySQL 排队最多 1 秒。到期把机会留给下一集，恢复该连接原有超时。零间隔跳过派发时间写入，非零时保留跨消费者间隔。重试持久化后按到期时间派发，重启或进程外改动通过有界恢复扫描发现，间隔复用心跳配置。已撤销的索引按精确块 ID 与当前版本重读，旧回执不能清除新工作。
3. 缩小成果提交事务读取和锁定的窗口集合。摘要在末窗口就绪后读取完整输入并复核指纹。索引先核验发布、生成代和内容版本，收尾只使用任务状态与版本。租约回收复用心跳与维护间隔中较短者，协调器退出后仍能完成或恢复。编码循环中的本地取消标记负责快速中断，模型准入、写 checkpoint、ES 发布前及最终提交继续校验租约和版本。已冻结的 Event 索引目标来自本次任务快照，加载与提交时继续比对。
4. 仅调短轮询或提高并发不能消除重复读取。搬迁向量/计时数据需要迁移历史记录。先采用具体 ID 和 SQL 状态投影，复用当前表和恢复协议。

### 动画并发时的状态读写

11 月 5 日 MyGO 第 4 集单独完成用时 848.4 秒。11 月 7 日第 1、2、3、5 集在六秒内提交，分别用时 1943.6、4382.3、3287.7、3344.0 秒。均为每集 24 块、22 个窗口、3 FPS，冻结并发为 10/10/1。第 5 集入队后等了 466.1 秒才开始，第 2 集经历两次结果校验失败及重试。动画执行于 `d54dfbde`，未加载本 PR。不能从不同集、不同并发批次直接计算程序加速比。

此次 MyGO 测试库单独的 SQL 摘要记录了 1,049,817 次窗口续租更新和 384,071 次块续租更新。Gateway 在读取每个 SSE 块时执行控制回调，旧解析宿主传入的回调逐次更新 MySQL 租约。每个 worker 已有定时续租，模型控制器也会在失去租约时取消本地传输。此处复用 [PR #64](https://github.com/owariband/Seekino/pull/64) 的本地取消回调，不引入草稿存储的表和配置。模型准入、业务工具、结果提交仍校验有效租约。理解 worker 复用本次租约已取得的输入快照，验证提交后的租约回执只读对应的版本字段。保持崩溃、暂停和运行中计时的既有采样口径。

同一批还记录了 54 次相邻 refine 请求因成员改版而中断。用本进程已知的运行窗口对就绪 ID 排序，优先领取与运行中窗口共享成员较少的候选，重叠候选仍可占用空位。暂停已撤销子租约，其结果保持原状，恢复扫描在分页和持锁复核时都排除暂停任务。

验收使用相同动画 SSE 序列回放，记录逐块续租 SQL 数和结果一致性。用真实 MySQL 测定时续租、暂停、回滚和竞争条件，再用同一集的正常解析入口检查实际耗时。分别报告模型实跑、回放及多集负载的覆盖范围。

第 3 集试跑中，14 个窗口提交后另 8 个窗口长时间续租。抓取的一次 MySQL 快照没有锁等待，同一秒的线程样本却有 8 个线程在 TLS 读取上等待。检查窗口输入改版时的取消路径，使用本地 HTTP 与 HTTPS 服务模拟「已收到首块、正在等下一块、此时取消」。测量从取消到原请求退出的时间，核对旧结果被丢弃、原租约可以继续作业。整集试跑的代码版本和后续复现分别记录。

# 5. 试点验证与方案取舍

先用隔离队列验证混合阶段、版本重建、租约失效和多消费者共享容量。以同一视频、并发、embedding/ES 配置比较索引吞吐、空槽和收尾，分别记录模型请求用时及整体时长。保持原结果可用。状态遗漏、提前完成或出现重复索引时暂停推广，通过持久状态恢复。模型费用、真实 ES 可见性和持续运行效果按实际覆盖报告。

**试点修正。** 11 月 7 日第一版只去掉全量查询，同样 12 块用时 53.154 秒，原版 45.018 秒。新候选已在内存，但忙父行仍会跳过，空槽等到下一轮。有界等锁首次复验时 15 次忙锁全部取得。带探针的正式对照中，原版跳过 21 次，修复版 10 次遇忙均取得父锁。六个消费者的真实 MySQL 竞争测试与等锁超时恢复连接的用例均通过。714 个定向回归和 30 个真实 MySQL 用例通过，扩大回归时复现的既有夹具问题见实验记录。
