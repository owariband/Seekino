# 1. 问题与现状

2026-11-25，0.2.19 的「向量嵌入」只能选服务连接。虽然已用 Qwen3 完成一次真实视频验收，用户仍须在应用外启动推理服务。分支 `feat/desktop-local-embedding` 依赖 [PR #190](https://github.com/owariband/Seekino/pull/190)，先合入上游。

# 2. 影响因素、假设与评价指标

首次下载约 639 MB，取消、断网或校验失败时要能重新下载。权重、分词、池化、查询指令和维度共同决定索引兼容性。验证同一文本的编码结果、现有资料库的切换保护，以及应用运行时是否启动推理子进程。

# 3. 改造方案与建模

「向量嵌入」并列提供 API 和本机模型。应用负责在用户数据目录安装并校验固定版本 GGUF，多座资料库可以共享权重。直接加载随包发布的 llama.cpp 库。下载完成后用户保存模型用途，只有选用本机模型的资料库在编码时加载权重；已有 API 配置沿用原绑定。

# 4. 对照实验与结果分析

沿用云端 Qwen3-Embedding-0.6B Q8_0、1024 维与 b12283。用相同文档和带查询指令的问题对照 llama.cpp 参考输出。验证错误下载不会覆盖有效权重，并从新资料库执行导入、发布索引、描述检索和按命中区间回看。
