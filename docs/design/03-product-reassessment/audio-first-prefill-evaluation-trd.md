# 3. 改造方案与建模

第一轮：按ASR已知范围建立有界音频窗口，用既有CAM++编码、现有匿名聚类方法生成分组；保留原WhisperX ID作为原始证据，不把它作为真实人物标签。输出匿名分组和逐cue预填，混合范围保留未知及细分声音区间。

第二轮：按原实际提交顺序取16/24份首次理解，给预计算窗口绑定具名表达参考。可复用同模型、同PCM、同精确区间的向量；不同区间不能冒充同向量。复用现有B0评分、目标／同cue／重叠排除和分档，再用真实Canvas构造器验证预填。剩余1/3提交后补齐锚点，完整重评分，区分16块时结果和最终全池结果。

匿名分组与人名评分分别评估；不能用一轮中的人物标签反过来改善另一轮的声学分组，并将其算作ASR后能力。当前先验证决定方向的假设，不修改生产调度、租约、来源快照或ready提交合同。

# 4. 对照实验与结果分析

比较三组：原Understanding区间B0基线；ASR先算窗口＋16块姓名锚点；相同窗口＋全部24块姓名锚点。优先采用已有算法及默认参数，探索性分段／聚类参数在运行前记录。保存ASR与媒体SHA、encoder合同、命令、实际编码数、分组结果及逐目标预填证据。

整集实测与[可复现报告](../../report/agent/video_parse_v2/audio-first-prefill-evaluation-20261115/README.md)已留存。第一轮只读取ASR、媒体与encoder：1001个窗口，16.886秒，其中编码15.501秒；默认AHC余弦距离0.35产生749组、626组单窗口，仅17/166条cue聚合为单一ID。36个过短cue合计4.462秒，占ASR总时间989.710秒的0.45%；不能把749组当作749人，匿名分组尚未通过稳定身份预填验收。

第二轮按实际Understanding表达区间补算：308个查询仅6个直接命中第一轮区间、4个命中前面已算的重复表达，实际原生编码298次、8.320秒。复用同一批缓存再次运行，两轮均0次新编码。共享整集PCM与旧逐段裁音频不同，303/308个PCM哈希改变；精确表达全池控制组top1全部不变、3条分档变化，不能宣称逐分数完全复现。
