工作分支：`fix/restore-celadon-palette`；目标分支：`dev`；PR：[PR #127](https://github.com/owariband/Seekino/pull/127)。上游为 [Apple 式视觉刷新 TRD](apple-style-refresh-trd.md) / [PR #90](https://github.com/owariband/Seekino/pull/90)，已于 2026-11-10 合入，随后经 [PR #93](https://github.com/owariband/Seekino/pull/93) 进入 main；本次不回退其字体、动效、菜单和功能改进。main 发布使用独立 [PR #128](https://github.com/owariband/Seekino/pull/128)，只携带运行必需的样式文件；先合入 #127，再合入 #128。

现状证据：`cee43f96` 在 2026-11-10 18:03:21（UTC+8）替换 `web/src/styles/global.css` 色板，并修改顶栏、首页和系列页的背景。恢复基准为该提交的父版本 `cee43f96^`；当前色板在 `origin/dev` 与 `origin/main` 中一致。11 月 9 日的主题渐变保留原色值，不是本次底色变化的来源。

边界为全局背景／表面／文字配色，以及本次改版更改的顶栏、首页和系列页固定颜色与遮罩。保持字体、字号、布局、圆角、动效、主题持久偏好、模型菜单、播放与数据契约。

# 2. 影响因素、假设与评价指标

全局 CSS Variables 决定各业务页的底色；首页和系列页另有固定的 Hero 背景与遮罩。只恢复 `--canvas` 会留下纯黑 Hero 和不匹配的灰白文字，因此按原提交的配色变更逐项恢复，不整份覆盖 CSS 文件。

| 指标 | 当前基线 | 恢复目标 | 验证方法与证据 |
| --- | --- | --- | --- |
| 白天／黑夜画布 | `#f5f5f7` / `#000000` | `#e4eae5` / `#121816` | Chrome 精确 RGBA 取样，16 个页面状态通过 |
| 白天／黑夜面板与卡片 | 中性灰白／灰黑 | 与 `cee43f96^` 的配色一致 | 源码对照、Chrome 取样通过 |
| 首页、系列页 Hero | 中性黑背景与遮罩 | 原绿黑背景与遮罩 | 2 页 × 2 主题 × 2 视口取样与截图通过 |
| 既有功能与视觉改进 | 新字体、渐变、动效、模型菜单 | 保持 | CSS 非配色部分相同；构建、2 项单测与现有主题回归通过 |

# 3. 改造方案与建模

在既有样式职责内恢复颜色：共享色板仍在 `web/src/styles/global.css`，顶栏材质的颜色归 `app-shell.module.css`，首页与系列页固定遮罩归各自 CSS Module。保留 `--night-mix`、主题初始化和浏览器偏好，亮暗切换继续使用已有插值。

先记录 TRD 初稿，再改样式。逐个核对 `cee43f96` 的颜色 diff，只恢复配色和匹配的背景绘制，不改组件、API 或测试逻辑。恢复原浅色光晕，顶栏回到原面板底色，Hero 恢复原绿黑背景与相应文字／按钮颜色。

无数据迁移、接口或持久配置变更。CSS 回退可以通过反向应用本次修复完成；不回退 PR #90 整体，避免影响后续功能和交互。
