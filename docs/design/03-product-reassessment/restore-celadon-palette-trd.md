# 3. 改造方案与建模

**Hero 共用背景方案：** 将 `#0d1110` 收为共享 `--canvas-night`，canvas 与 Hero 角色共同消费。共享 `--hero-base`、`--hero-shade`、`--hero-bottom` 保留白天原底色与遮罩，夜间统一到同一 canvas。两个页面的桌面 / 移动遮罩只保留各自布局和透明度，颜色由共享角色提供；系列页移除重复的日间底部颜色覆盖。主题进度继续使用原 `--night-mix`，避免用正在变亮 / 变暗的 canvas 重复插值。运行范围为 global.css、watch.module.css、series.module.css。
