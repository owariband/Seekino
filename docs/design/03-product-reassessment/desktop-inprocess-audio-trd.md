# 1. 问题与现状

2026-11-26，桌面 0.2.21 能在进程内运行 Qwen3，但转写需要配置外部服务，CAM++ 只在后端开发环境验证过。分支 `feat/desktop-inprocess-audio` 接在 [#192](https://github.com/owariband/Seekino/pull/192) 后。交付目标是在同一个 Seekino 应用进程里把原片声音转成带时间的台词，并对有依据的台词片段计算声纹。

# 2. 影响因素、假设与评价指标

用有人声、包含不同说话人的片段衡量。转写应保留分段及真实时间，声纹要比较同一人与不同人。包内运行时、模型文件、设置绑定和 V2 任务都须接通，独立向量或文本输出只能验证模型本身。

# 3. 改造方案与建模

保留服务端和自备 API 的入口。桌面提供按需下载的本机 Whisper、可选 CAM++，复用资料库模型用途设置、权重校验和原有任务快照。采用 native library 在调用进程推理。Qwen3 仍专用于文本检索，现有索引沿用原合同。平台各自打包原生依赖。

# 4. 对照实验与结果分析

在本地语音样本上验证 Whisper 时间戳及 CAM++ 维度、同异人排序。验证权重缺失、重复开关及重开资料库；比较既有 API 路径。正式解析任务要核实真实调用和持久化结果。

# 5. 试点验证与方案取舍

在 macOS 安装包检查运行时加载、原片解析与进程树。Windows x64 包检查依赖闭合；实机成绩单独记录。
