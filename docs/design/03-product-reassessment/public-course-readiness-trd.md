## 3. 改造方案与建模

- **系列归属和可见性。** 管理者显式设置 `visibility`。公开目录及详情以系列、有效发布者和读者身份授权；空系列也可以公开。现有成员和公开字段投影继续使用。播放地址按每集已上传的受管原片和浏览器兼容性生成，Range 每次回到 API 鉴权。
- **当前对话。** Web 保留已授权系列、来源 tenant 以及观看集和毫秒时间。服务端保留每一轮授权范围供追问、历史和撤回校验。普通文本回答及可直接读取原片的实时理解各走现有入口。空检索范围不得扩到其他课程。
- **可信检索范围。** 普通搜索、Agent 的 Chunk 和 Event 工具复用 V2 最新任务和内容版本核验。整课只搜索最新任务 COMPLETE 的集，按实际范围输出 `searchedVideoIds`、`partial` 和面向用户的集数提示。显式单集请求先在授权课程内解析目标 videoId，再在 SQL、召回和证据核验中限定目标。零就绪、有覆盖但无匹配、向量服务故障分别反馈；工具失败可让 Supervisor 继续回应。
- **数据与兼容。** 旧调用缺省按整门课程检索。沿用现有表、ES 投影、索引版本和时间单位，无需启动 GPU、回填素材或重建索引。

## 4. 对照实验与结果分析

在隔离环境构造同一门八集公开课程，分别设置最新任务为七集完成加一集索引中、八集索引中、撤回公开。对照相同输入下的 HTTP 状态、可播链接、聊天历史、召回前的授权 video/task 范围、返回证据来源及用户提示。增加向量服务断开、无命中和无权 videoId。保留上表的现场基线，改造结果待测。
