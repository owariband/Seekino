# 3. 改造方案与建模

在现有 Refine Prompt 中补一个段落：声音可早于人物出镜、来自画外，或在他人反应镜头上继续；可见、张口或旧描述的发言归属不能单独推翻对应区间的声纹依据。保留受支持的视觉动作，同时复核描述中推断的说话人，让其与最终 speaker 一致；证据不足时保留不确定性。

流程仍为 Understanding → B0／prefill → 完整 JSON Refine → 原事务提交。代码改动仅在 `agent/video_parse_v2/prompts.py`，不新增抽象、字段或模型工具。模型档位通过本次任务的既有 parse config 指定，不改共享开发配置。
