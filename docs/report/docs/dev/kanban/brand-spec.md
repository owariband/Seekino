# Seekino 项目看板品牌依据

日期：2026-11-02。范围：一个可离线维护的 HTML。

品牌源自仓库现有 [Seekino Logo](../../../../../assets/mascot/seekino-logo.svg) 和 [前端样式](../../../../../web/src/styles/global.css)。HTML 内嵌原 SVG，不额外生成品牌图，不请求远程字体或图标。

| 用途 | 实际采用 |
|---|---|
| 页面底色 / 次级面 | `#e4eae5` / `#ebf0ec` |
| 卡片 | `#f6f8f5` |
| 正文 / 辅助文字 | `#17312b` / `#566b65` |
| 链接与主按钮 / 状态强调 | `#126b5d` / `#238c78` |
| 等待提示 / 正在推进 | 土黄色标签 / 蓝色标签，均配文字 |
| 字体 | 沿用前端无衬线字体栈，优先本机可用字体；编号使用等宽字体 |
| 字号 | 桌面正文 14px、辅助信息 12px；手机正文 16px |
| 触控目标 | 按钮、输入框、下拉框不小于 44px 高 |

宽屏以左侧分类导航和分类泳道为骨架。每个泳道固定 TODO / PROGRESSING / DONE；每列初始最多三张卡片，可展开。手机保留三列关系，在泳道内部横向滑动；整个页面不横向溢出。

原 huashu-design 检查器的中点分隔、等宽编号、Inter 标题属于黄色风格提示：此处编号是问题/PR 的真实标识，字体沿用现有产品，不为避开提示改造信息结构。两种宽度均没有字号、对比度或破图红灯，见 [设计检查](design-check.json)。
