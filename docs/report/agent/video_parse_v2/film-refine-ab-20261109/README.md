## 这次要看什么

让两个新的官方 DeepSeek Flash 编辑会话各自从零交一支可播放的片。片主先盲看两支片，选更愿意给别人看的一支，再看谁用过全片 Refine 风格卡，以及实际花了多少时间。一个会话一支片，可以发现具体得失；仅凭这一对成片不能估计整个素材库平均能节省多少时间。

## 沿用的创作要求

- 采用 11 月 7 日实际试剪的《Weekend》委托。戴眼镜的爱音想学 LLM，被一堆课程和 PPT 难住，咬牙、双拳攥在脸边；接着瘫到沙发上，拿设备准备玩。Kino 帮她把一个问题定位到真实课程中的一段，她重新有了兴趣。保留 #50 的真实提问、带时间的结果和原片回看。
- P5R 给美术和动作提供参考，具体手法、字体、配色和节奏由编辑决定。上一轮盲评认为爱音的角色素材和 P5R 风格辨识度仍可改善。这次要求编辑在原片里自己找表演、自己分离并入片，同时保留选择手法的自由。
- 沿用太妍《Weekend》原录音、无新增配音、横屏 1080p、30 fps。约半分钟是工作尺度，乐段与片长自定。#50 在 11 月 5 日的早期宣传片委托写过“无配乐”；本稿选择较晚、已实际试剪的音乐版本，供此次审阅确认。
- 音乐、字体、Kino、Seekino 的真实界面与课程问答证据相同。两组各自取材、写分镜、做美术、混音、看导出并自查。主持人只处理对照、技术核验及匿名展示；如需代作创意或剪辑，记明介入，保留介入前版本并判该组自主交片未完成。

## 本轮使用哪一批素材

- **角色正片。** 首轮建议用已经验过 MCP 的 MyGO EP01–05，两组固定到同一批已发布任务版本。开剪前核对 MCP 的系列、搜索、翻页与原片回看，并在清洁的新工作区里验证同一人物分离脚本。给导演剧本、工具和库入口；主持人选好的镜头、透明 PNG、旧片单、目标集数与命中时间都留在工作区之外。
- **剪辑参考。** 两组都可观看选定的 Persona 三支 OP（P3 Reload、P4、P5R）和 `assets/anon_ref` 七支爱音剪辑。只有 P5R 已有本轮成对比较的 8 段笔记和自动卡，其余九支均以原片对等开放。参考片回看与笔记使用同一只读实验入口；正式版参考 MCP 仍待接入。这一轮可评成片与本机剪辑流程，十支完整解析及 MyGO 全系列仍是后续的全库验证范围。
- **产品与课程。** 两组都可查同一课程证据、回看来源，并使用已核过的 Kino、logo 和 UI 素材。宿主只提供真实功能依据。卡片、截图或素材文件出现在库里，并不指定必须采用何种呈现。

已核对的原片名、静态文件指纹、笔记与卡片来源、已有五集任务版本可见[主持人输入清单](review-inputs.json)。开剪前在独立编辑工作区只挂载上述素材和工具，不暴露过往试剪、红底成品、实验报告或另一组工程。若实际发布版本或素材覆盖与审稿有变化，记录差异；已验证的五集不能记作全系列验收。

获批执行时按导演稿从实际产品的 `web/src/shared/kino/engine.ts` 导出 11 组透明像素动画。旧包里三个平滑线条的 Kino SVG 均不投给导演。复核了克隆测试库的 5 个已发布版本、4 个 MCP 工具、自然语言检索、按人物翻页以及证据原片的 HTTP 206 回读。两组独立工作区使用相同的素材、镜头检索和本机分割工具。

## 执行与交片

1. 本稿获批后，用两个独立的 `deepseek-official/deepseek-flash` 会话，思考强度均为 `max`，沿用此前实剪的 `motion-showreel` 和本机媒体工具。两组使用相同机器配置与同一导演时间预算，本稿拟定每组最多 65 分钟。两组串行、次序随机，避免争抢本机渲染资源。发生可恢复的工具或网络中断时，在本组工程及剩余时间内继续并记账。
2. 两组都会多轮调用官方 `api.deepseek.com`。发给模型的是同一委托、各自允许看到的参考文字、检索结果与时码、所选候选／本组成片的核对缩略帧，以及必要的源码与工具反馈。原始视频、整首歌曲、分割推理与渲染在本机处理。两个编辑会话各自做创作决定，实际费用和用量归组记录。这是两次完整制片任务，调用量按实际步骤统计。
3. 每组交实际导出的 MP4、可编辑源码与重建命令、用片与用曲表、一次实际使用的人物分层和红底预览。用片表分别记录原始片段范围、用片入出点及成片入出点；定格、重排与合成如实标注。主持人检查全片可解码、有可听音轨、音乐来自给定录音、人物和产品证据可回源，复核抠图是否在成片里出现。
4. 给片主的第一页只显示两支随机中性编号的成片，使用相同播放器和音量设置；映射单独封存。先记录“更愿意发布／重看哪一支”，允许持平或两支都不采用，再记最影响判断的成片时刻与理由。重点看爱音的情绪和设备动作是否读得懂、Kino 的帮助是否说清、P5R 手法是否合适、音乐和文字有没有盖住表演。选完再揭晓分组。
5. 另报从收到委托到首个可播放版本、到最终导出的总用时，本机渲染等待，取材与返工次数，模型用量和人工介入。两组均保存提示词与输入哈希、会话记录、工具调用、来源、成片哈希、失败与盲评映射，便于查明差异。
