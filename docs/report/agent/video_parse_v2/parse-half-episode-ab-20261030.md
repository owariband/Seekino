## 时长、用量与边界

B 十次完整响应耗时 92.02–143.89 秒，中位数 **109.52 秒**；首正文等待 61.42–82.84 秒。十次请求合计 1135.02 秒；加第十一次 90.76 秒超时和本地开销，实际尝试墙钟 **1226.20 秒（20 分 26 秒）**。这是处理到前十分钟后失败的耗时，不是完成十二分钟的耗时，也不含共享 ASR/抽帧。

每块秒数依次：92.02、118.40、143.89、106.59、95.08、102.07、126.75、112.45、103.53、134.23；第十一块 90.76 秒超时。没有 p95/p99 稳定性结论。较早 38.01 秒是另一次单块样本；两次服务等待、缓存、ASR/前文均非完全相同，不能将本次变慢归因于串行或 thinking。

Provider 实报 B：**2,517,767 input + 19,434 output = 2,537,201 tokens**。B 超时请求及 A 两次尝试均无可用 usage，因此这不是总消耗，也未换算费用。B 完整请求的 reasoning_tokens 都为 0。运行准备与恢复占用了过多交付时间，且没有拿到 A 正文；不能用这些工程活动抵消未完成对照。
