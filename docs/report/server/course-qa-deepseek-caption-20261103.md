## 原片、回看和持久化核对

观看工具返回的来源包括 **47.640–61.180 秒**的概率系统说明，以及 **85.380–94.720 秒**的树叶新闻朗读。两组都保留了原话与补充解释的区分。第二组 Q02 将“预测下一个 token”放进解释，直到 Q03 才精确承认原话在所引区间只支持“概率系统／同一提示多个答案”；因此来源表述还需要收紧。

人工核对 90 秒原帧：LearnGPT、树叶提示、生成新闻及右下角讲师画面均可见。视觉输出还把左侧背景编辑器叫作 Xcode，这项识别缺少画面支持；核心画面事实正确不等于全部细节通过。

在第一组完成的真实页面点击 Q03 的 **01:25** 来源，播放器从 **90 秒跳到 85.4 秒**；显式播放后推进到 **85.973 秒**，媒体无错误，新增模型请求为 0。标签显示到整秒，实际跳转保留小数。验收脚本最初错误地按显示标签期待 85 秒，已按来源区间修正为 85.4 秒，保留原实测位置和修正说明。

两组刷新后消息与回答保留，正文差别仅为临时“回答已完成”播报消失；浏览器 `pageerror` 均为 0。本轮没有重复验证 HTTP 幂等、取消、崩溃恢复，也没有独立计量 seek 或刷新延迟。
