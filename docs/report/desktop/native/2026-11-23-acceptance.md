# Seekino.app 安装候选实测

2026-11-23，在 Apple Silicon、macOS 26.5.1 上，用 CPython 3.12.16、Swift 6.3.3、PR #183 的 PyAV 19.0.2 和 FFmpeg 9.0.2 自建 wheel 验证 [PR #184](https://github.com/owariband/Seekino/pull/184)。App 声明最低 macOS 15，包内最高 Mach-O 部署目标来自 orjson 扩展。macOS 15 真机与 Intel 尚未测试。

| 操作 | 实测 |
| --- | --- |
| 建库与搜索 | 空 SQLite 库通过桌面调用入口导入两秒的带 AAC 音轨样片，V2 固定模型回放完成。关键词“红旗”和描述“挥动旗帜”均返回原片 [300, 1200) ms，回源文件与输入字节相同。固定回复在独立 Python 回放中提供，使用候选包的依赖。 |
| 原生播放 | 搬移并验证签名后的 App 在空 PATH 打开已索引的库，Swift 调用同一搜索入口和证据复核，首个画面与 PCM 样本均为 300 ms。播放时钟推进到 487 ms，暂停跳转稳定在 200 ms。App 观测为 0 次 fork 或 exec，观察器对照能捕获短命子进程。 |
| 原生画面 | 在本机 SwiftUI 窗口预填搜索后选择命中，显示片段时间、来源文件及连续播放后的红色测试帧。预填命令只加入临时视觉检查副本。按该进程 PID 查询，本机 TCP 监听和子进程均为 0。 |
| DMG | 本机 ad-hoc 签名包通过磁盘映像校验、只读挂载和复制后的严格签名检查。从复制出的 App 重开同一 SQLite 库，仍命中 [300, 1200) ms，首帧与音轨为 300 ms，暂停跳转为 200 ms。 |
| 回归 | SQLite、存储配置和空库 22 项通过。桌面 V2、VideoToolbox 媒体和上传恢复 11 项通过，两组共 33 项。 |

第一版播放在创建带自定义 IOSurface 字典的视频缓冲区时崩溃。调用栈落在 CoreVideo 的 `CVPixelBufferCreate`。改用默认缓冲区属性后，测试程序和实际窗口均成功输出画面。自动播放验证以静音运行，音轨使用解码出的 PCM 时间检查。

本地 DMG 为 89 MiB，SHA-256 为 `e172bb18b3a6f2e2cdedbc05f51905b44b4da8395d5e0b48a658d51c453397fd`。候选 App 含全部 Python、模型 SDK、SQLite 扩展和媒体库，安装时从 DMG 拖入 Applications。安装、签名与复跑命令见 [桌面构建文档](../../../../deploy/desktop/README.md)。

下一轮使用实际模型凭据和用户的短片及长片验证解析质量与响应，检查发布签名及公证后的干净机器启动、连续长片音画和跨版本升级。当前机器签名钥匙串没有有效的 Developer ID Application 身份，因此这份产物供本机验收。进度见 [工作台](../../../dev/workbench.html)。

## 0.2.0 的窗口、动效和安装

验收重新以当前分支的 Web 页面为视觉基线。两边使用独立资料库导入同一部仓库宣传片，时长 62,200 ms。首页的大图和封面都取自受管原片。Mac 窗口保留系统红黄绿按钮，42 pt 工具栏容纳 Seekino 字标和搜索入口，资料树直接展开系列与视频。桌面搜索复用 Web 的像素 Kino、居中换行的建议词和 116 px 高的输入区。 [Web 首页实拍](web-style/web-home.png) · [Mac 原生窗口实拍](web-style/desktop-home.png) · [收起资料树、搜索及回看片段的静音录屏](web-style/search-and-play.gif)

| 验收项 | 结果与条件 |
| --- | --- |
| 窗口和动效 | 在 1080 × 700 窗口真实点击资料树、搜索建议、搜索结果及播放器；折叠过程中观测到多个中间宽度。启用减少动态效果后，第一次刷新即到最终宽度。640 × 440 小窗口仍可滚动到搜索和筛选控件。 |
| 播放 | 对 62.2 秒的宣传片，控制条在闲置五秒后隐去，移动指针后重现。暂停、进度条、键盘跳十秒、全屏与 Esc 返回均走通。静音验证。 |
| 应用包 | 从最终 DMG 只读挂载，复制到新路径并严格验签。固定模型回放导入两秒样片，关键词与描述均命中 [300, 1200) ms。空 PATH 下从复制出的应用回看，首帧、首段 PCM 均为 300 ms。暂停后定位 245 ms，渲染像素与原片解码相符，继续播放成功。系统观察器通过阳性对照，回看时记录到 0 次 fork/exec。 |
| 原资料库 | 在上一版资料库副本运行搜索和原片定位，关闭后对照 37 张表、234 条 schema 记录和受管原片哈希，结果一致。资料库格式仍为 v1。 |
| 回归 | 桌面控制器、真实封面、SQLite、任务租约、导入恢复、解析、检索与媒体测试共 69 项通过。 |
| Windows x64 | 构建了同一套页面的 ZIP；校验归档 CRC、37 个桌面源码与美术文件、305 个业务源文件。205 个 PE 均为 AMD64，包内 DLL 导入符号完整。唯一 EXE 为带图标的 Windows GUI 程序。Windows 真机启动、凭据写入与连续播放留待验收。 |

Mac DMG 共 123,649,712 字节，SHA-256 为 `e1d19233957e94b3ab965c789ae5a77255595e04e76d8fe6e3e9c3381f65d017`。Windows ZIP 共 148,748,200 字节，SHA-256 为 `4c6c16eed0f31f9751e11ad9ba1b2b0546349d7b66c4a8a787e02843915013d0`。Mac 验收环境为 Apple Silicon、macOS 26.5.1。60 秒宣传片用于视觉和播放验收，解析与搜索精度的测试数据为单独的固定响应短片。实际模型、长片、目标系统版本、干净机器和正式签名仍未验证。

## 0.2.1 的品牌与比例复核

macOS 和 Windows 使用同一份白底 Seekino 字标。窗口工具栏截取方形应用图标中的字标区域，实际尺寸为 96 × 28。Mac 从最终 DMG 挂载、严格验签、安装并打开了 1080 × 700 的应用窗口。独立资料库的固定模型回放完成了导入、解析和两种检索，回看命中区间为 [300, 1200) ms，系统观察器在该次回看中记录到 0 次 fork/exec。Windows x64 安装归档通过 CRC 校验；从 EXE 提取的七档图标（16 至 256 px）均与同尺寸的字标像素一致，实际 Windows 窗口和任务栏仍待真机验收。 [Mac 实拍工具栏局部](web-style/white-wordmark-mac.png)

在同一部宣传片、1080 × 700 逻辑窗口下，用上一版两端的首页实拍与对应 QML、CSS 核对了以下差异。本版的界面改动限于品牌展示，比例记录可供下一次视觉验收使用。

| 项目 | Mac 桌面 | Web | 观察 |
| --- | --- | --- | --- |
| 首页 “Kino” 与「视频系列」 | 约 44 / 25 | 54 / 25.6 | 主标题随展开资料树后的 875 宽内容区计算，Web 随整个窗口计算。两端主标题字重均为 700，标题和栏目名之间的字号差在桌面更小。 |
| 说明至「播放本集」按钮 | 间距 20，按钮 111 × 40 | 间距 30，按钮 135 × 48 | 两端「从这里开始」的文字顶部仅差约 1，但向下到按钮，位置相差约 50。 |
| 首页系列封面 | 787 宽的区域排四列，卡宽约 183 | 横向排列，卡宽约 272 | 桌面首页与选集共用换行网格；Web 首页提供横向系列浏览，系列详情使用独立网格。 |
| 搜索输入框 | 760 × 116 | 约 746 × 116 | 输入框顶边相差约 1，两端发送按钮均为 34 × 34。 |

数字使用逻辑像素。Mac 首页面板的源实拍为 2× Retina，已按窗口尺寸还原。字体、边距与网格的出处分别为 [桌面首页](../../../../desktop/ui/BrowserPane.qml)、[桌面按钮](../../../../desktop/ui/Tool.qml) 和 [Web 首页样式](../../../../web/src/features/player/watch.module.css)。本次 OpenCode 对 OpenRouter Claude Opus 5.5（high）的请求收到地区限制 403；以上结论来自本地实拍和源码核对。

## 0.2.2 的应用图标、工具栏与外部视觉复核

白底 Seekino 字标用于 macOS 和 Windows 的系统应用图标。窗口工具栏恢复了 0.2.0 的透明背景和随主题变化的文字颜色。Mac 包中的工具栏组件与 0.2.0 逐字节相同，ICNS 与 0.2.1 逐字节相同。Windows 包内工具栏也已核对，EXE 的七档图标经解码与 0.2.1 逐像素一致。Mac 最终 DMG 的固定响应回放走通导入、解析、两种搜索和命中回看，回看期间系统观察器记录到 0 次 fork/exec。Windows 实际运行仍待真机验收。 [Mac 实拍工具栏](web-style/toolbar-0.2.2.png)

OpenCode 经这台 Mac 已有的 Clash Verge 代理，将 1080 × 700 的原生和 Web 实拍对照发给 OpenRouter。会话记录确认模型为 Claude Opus 5.5，推理级别为 high。评审指出主要差异在资料库首页：主标题和播放按钮的视觉分量偏小，资料树项目也显轻。对照上节的实测，主标题两端字重相同，字号约为 44 和 54；按钮高度分别为 40 和 48。资料树行高实为 28，名称与数量字号分别为 12 和 10。评审对中文字体回退的猜测尚无运行证据。搜索输入区的尺寸与前述实测吻合。字号与间距的调整未纳入这次图标修正。
