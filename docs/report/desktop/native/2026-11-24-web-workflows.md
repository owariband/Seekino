# 0.2.13 桌面工作流验收

Web 对照以发布分支 `main@f7823c8d` 为准。桌面基线为 0.2.12，原生宿主、SQLite 和进程内 FFmpeg 的调用方式沿用上一版。[设计与验收依据](../../../design/03-product-reassessment/desktop-web-workflows-trd.md) · [PR #186](https://github.com/owariband/Seekino/pull/186)

| 操作 | 旧版复现 | 新版实测 |
| --- | --- | --- |
| 首页与逐集续看 | 先看 B1 到 12 秒，再看 B2 到 32 秒，B1 从头播放 | 同系列两处位置都保留。另看 A1 到 4.5 秒，首页转为 A1。退出进程再开 B1，回到 12.000 秒 |
| 播放与查找 | 系统查找键离开原片；没有倍速入口 | 本集对白、画面文字与场景可在原播放器查找。实际点击 MyGO 样片的场景结果，落在 4.250 秒；从另一条片内结果跳到 750 毫秒。六档音画速率实测约 0.49 到 2.02 倍，固定音高信号经 atempo 后音高保持 |
| 陪看 | 发问时暂停，收起后仍暂停；重开时对话丢失 | 按偏好随发送暂停、收起恢复。停靠栏从 440 拖到 508 像素，浮动后重新停靠仍保留宽度，浮窗可以切集。Ark 与 OpenAI 兼容协议的回答逐段显示；停止后重开，保留停止前的文字。多轮回复与图片随资料库保存 |
| 搜索与引用 | 命中只能回看；没有跨系列问答 | 在搜索页选系列问 Kino，从回答引用回原片。也可直接从关键词命中引用并提问。验证命中区间为 300–1200 毫秒，并核对请求包含真实原片帧 |
| 首次导入与解析 | 没配模型时，选有效文件直接打开设置；素材数没有变化 | 文件清单可改目的系列和集号，能逐文件暂停、重试和取消。无模型时临时库从 3 部增加到 4 部，已能播放。重开后补配置，测试回放跑通 V2、关键词与向量检索 |
| 系列与任务 | 修改集号、资料、导出、重新解析和历史清理缺少入口 | 从系列操作修改集号、ASR 语言和背景，按视频和事件类型导出 JSONL。临时库创建 v2、单独删除 v1，再建 v3 后清理全部历史。删除导入后外部原始文件仍存在。任务详情按当前任务读取进度和近 30 天已记录的用量 |
| 设置 | 模型 ID 手填，界面缺少语言、帮助和用量入口 | 对 OpenAI 兼容服务可按需读取模型列表，Ark 可填推理接入点。实测运行中切换 English、打开帮助和本地用量。旧地址的已保存密钥仅用于原先的服务地址 |

模型协议采用离线固定回复。已验证发送的文本、引用范围、图片和时序，线上模型输出质量与计费需单独实测。任务用量来自本机账本，缺失的历史调用记录按未知处理。账号、公开分享和多租户权限属于 Web 服务。桌面 Kino 使用本地检索与证据回源，Web Supervisor 的完整多步工具循环尚未接入。现有 Web 装配的持久检查点要求 MySQL，桌面缺少该工具集依赖的 Chunk 查询适配，区间抽帧和实时理解也需要接进程内媒体实现。Windows x64 验收覆盖包内文件和可执行文件完整性，窗口、音频设备和升级仍待 Windows 实机验收。

## 安装与进程观测

在本机 `/Applications/Seekino.app` 核对版本 0.2.13 和严格签名，继续使用原来的示例资料库。库中 3 部视频及 3 个暂停任务均保留。Apple Silicon Mac 的签名为本地 ad hoc；未做 Developer ID 公证。最终 Mac 和 Windows ZIP 分别对照了 382 个桌面与业务文件。

用最终包的业务代码和依赖运行固定模型导入，核对 V2 发布、关键词与向量检索、证据回源。再用移动后的原生可执行文件验证，命中为 300–1200 毫秒，首帧与首个音频包都在第 300 毫秒。macOS 观察器的阳性对照捕捉到子进程；观察 Seekino 检索和回放时未见 fork/exec。2026-11-24 15:29:58，本机打开示例库后 `top` 的主进程 MEM 为 384M，同次检查无直接子进程。此读数是该时刻的主进程占用。

桌面及直接依赖的定向回归为 512 项通过、28 项依赖其他测试环境的用例跳过。扩展回归共 2091 项通过、29 项跳过、1 项真实模型用例未运行，7 项失败。对 0.2.12 源码以相同环境单独重跑这 7 项，失败用例与末端错误均相同，涉及 Langfuse 请求头、默认模型配置与 DeepSeek 多模态/用量测试。
