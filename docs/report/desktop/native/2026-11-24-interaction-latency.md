# Seekino 0.2.15 桌面交互验收

2026-11-24 在同一台 Apple Silicon Mac 上比较 0.2.14 和 0.2.15。首页和启动比较使用解压后的安装包、三个本地系列的独立副本、1080 × 700 逻辑像素窗口。两组各起两个新进程，每个进程从同一系列返回首页四次。搜索的 Qt 渲染使用 Metal 与 120 Hz 显示器。数据来自应用实际加载的 QML、Python 与媒体库。[分项原始记录](2026-11-24-interaction-latency.json) · [设计](../../../design/03-product-reassessment/desktop-interaction-latency-trd.md)

| 操作和计时口径 | 0.2.14 | 0.2.15 |
| --- | --- | --- |
| 从系列返回首页到主图和三张卡片全部就绪，每个进程取后三次，共六次的中位数 | 224.6 ms，每次解码四次 | 50.3 ms，全部命中缓存，无原片解码 |
| 播放时跨过两次 10 秒自动保存 | 隐藏首页两次提取封面 | 隐藏页图片请求和解码均为零。返回后主图和卡片都取 22.357 秒处的画面 |
| 按住进度条连续移动，播放和暂停状态各 110 次鼠标移动事件 | 松手才开始定位 | 松手前分别绘制 16 和 10 张不同画面，首张预览约 99 和 95 ms。松手都准确提交 46.318 秒，并保留原状态 |
| 点击搜索到整页不透明度达到 0.999，五次中位数 | 294 ms | 98 ms，五次点击在事件处理当下已聚焦输入框。180 个输入字符都收到，按键到 Qt 提交画面的 P95 为 8.5 ms；另测了模拟的中文组字和提交 |
| 开始创建窗口到资料库就绪，各两次 | 5.34、5.61 s | 4.10、3.50 s |

单独测试后端启动，在六次新进程交叉测量中，读取相同系列和任务的组内中位数从 4.68 秒降至 2.78 秒。预编译的字节码逐份核验源码哈希，两个安装归档均比 0.2.14 大约 14 MB。首次开库仍需等待模型依赖导入以及正式服务初始化。以上计时终点分别是图片、解码帧、Qt 提交和业务就绪，不能互换。

## 功能回归

- 原生窗口逐集保存位置，切集、退出再打开后能从各自位置续看。无模型时仍能导入视频，临时库从三部增加到四部。设置可切换中英文，能进入用量、帮助和导入目标选择。
- 同一段素材分别以播放和暂停状态拖动，在 1.5 倍速、静音、音量 0.25 下保存设置。快速点按提交 20.321 秒。刻意延迟的旧片预览在换片后不会覆盖新片。
- Ark Responses 与 OpenAI 兼容 Chat Completions 各做一次包内流式回放。点搜索命中进入 3.300–5.200 秒片段，按斜杠打开片内查找，点选结果准确到 4.250 秒。从 Kino 浮窗和全库回答点击引用均回到同一段原片。全屏图标进入和退出后，同一集仍暂停在 4.250 秒。
- 从新的文件夹启动原生程序，使用固定模型响应完成导入、V2 解析、关键词和语义检索，验收命中区间、音轨、帧位置及 Qt 绘制像素。进程观察器通过阳性对照，实际运行 `--verify-library` 时未观察到应用 fork/exec。完整桌面与桌面后端的 74 项定向测试在可使用 VideoToolbox 的环境中通过。
- 签名完整性校验通过的 0.2.15 已安装至本机，原示例资料库仍有三部视频。Windows x64 归档全部 34,616 项通过解压和 CRC 检查。新增 1,095 个字节码文件按 Windows 目标源码重算哈希和编译结果；两个最终包的 383 份业务、配置和界面文件逐字节一致。

模型验收使用离线固定回复；触控、拖动与输入法使用注入事件。Windows 真机操作、真实供应商的回答质量以及 macOS Spaces 的物理全屏转场未在本轮测量。
