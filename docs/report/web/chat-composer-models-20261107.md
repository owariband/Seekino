## 本机产品入口

Chrome 实际打开 5188 的 `/search`，从 19641 的消息选项接口读取默认 `deepseek-flash`、豆包 Seed 2.0 Lite 和 Kimi K3.1 Pro。已有资料库继续使用原数据库和媒体。本机预览复制原有效配置，在副本中开放两个回答模型。没有迁移历史对话。预览的运行信息在本机 `outputs/local-services/kino-preview/chat-composer-api.json`。

| 操作 | 观察 |

| 打开草稿，选 Kimi，输入文字，打开图片选择器并取消 | 输入框、选项可操作。浏览全过程中，聊天接口写请求为 0 次 |

本机截图和尺寸原始记录位于 `outputs/verification/chat-composer-models/20261107/`，不上传真实聊天数据。

## 模型路由与并发

使用隔离 SQLite 测试 HTTP 创建、读取、列举、修改和重置。两份对话交替发消息，记录的模型与实际接到调用的测试 Supervisor 对应。切换后的下一条使用新模型，幂等重试返回原消息。测试覆盖其他用户无法改动会话、未知选项被拒绝，以及消息写入前遇到并发改模时返回冲突且无新消息。真实 Gateway 工厂的装配测试核对来源、模型名、输出限制、推理参数、检查点与 Query 模型。没有向供应商发起回答质量评测。

## 前后端回归

独立分支前端 611 项单测通过，合入播放器本地改动的版本 619 项通过，类型检查和生产构建通过。后端四个相关测试文件剔除经上游复现的三个旧断言后，511 项通过，1 项跳过。旧断言涉及历史默认模型配置，以及默认选择 Codex 的假设。前一次运行中一个流式快照用例偶发失败，单跑及上述重跑通过。

生产构建的 Chrome 套件 16 项通过，覆盖桌面与触屏历史、长草稿缩放、首发流式过渡及语言选择。两项账户测试未通过，对游客公开课程目录的相同预期在上游版本亦失败。上述上游对照使用 `e42d05a6`。本机真实浏览器另外核对了上表尺寸和配置选项。
