# 模型注册与用途分配验收

2026-11-08，本地设置工作树和测试部署。上游为 [#74](https://github.com/owariband/Seekino/pull/74)，本需求 [#76](https://github.com/owariband/Seekino/pull/76)。

| 验收入口 | 实测结果 |
| --- | --- |
| 5188 模型服务 | 显示生效 YAML 中的 8 个连接，包括尚未注册模型的来源。使用回环服务获取列表并登记视觉和转写模型，只有用户选中的项目被保存。 |
| 5188 模型用途 | 逐项比较六个选择器与服务端允许的模型。在页面修改 OCR，独立读取 YAML 和刷新后的选项，随后恢复原用途并删除临时服务。原文件逐字节一致，验收创建 0 个会话。 |
| 正常执行入口 | 在隔离配置上以同一地址、同一模型 ID 注册两把不同的合成密钥。回答探测使用第一把，画面理解、OCR、音频转写、索引和重排使用第二把。解析快照、图片载荷、向量维度、工具回传和结构化响应均有断言。 |
| 协议与目录 | 已注册视觉模型通过四种 HTTP 协议返回结构化结果。测试 OpenAI Audio 及 Ollama Embeddings 独立凭据、按连接读取模型列表，以及新用途读取旧环境覆盖模型 ID。 |
| 访问与并发 | cloud 游客和普通账号无法访问用途或发现接口。无权限访问任一设置深链都不加载注册信息。冲突修订与不兼容分配均保留原文件。 |
| 桌面与手机 | Chrome 覆盖桌面设置、草稿内打开设置、游客深链和 360px 窄屏视口。模型表单支持手填及发现失败后继续编辑。 |

本次未发起商业供应商调用或整集视频重解析。解析和检索使用 API 启动时读取的配置，换向量模型涉及已有索引的兼容或重建，验收未修改现有 ES 数据。扩展 Gateway 回归中有五项默认配置与多模态测试在父提交上也失败。[执行测试](../../../tests/server/test_model_registry_roles.py) · [页面测试](../../../web/src/features/settings/AnswerModelSettings.test.tsx) · [权限测试](../../../tests/server/test_cloud_access.py)
