## 设置展开栏

同一份配置下对照了 1360px 桌面和 320px、360px 手机视口的浅色与深色界面。用途行以模型名为主，来源单列到次行，展开列表按连接分组。服务列表用分隔线区分连接，只有打开的行显示地址、凭据掩码和操作。支持自定义选择器外观的浏览器使用 Seekino 的菜单样式，其余浏览器使用系统选择器。

在 320px Chrome 中，初版展开菜单的选项宽度仅约 134px，长模型 ID 需要折成多行。最终菜单宽 284px，选项可用宽度为 270px。键盘可展开服务、关闭选项，关闭设置后聊天草稿与选区均可恢复。本次外观复查只读本地配置。[浏览器回归](../../../web/tests/chat-layout.spec.ts)

在包含聊天重试提示和解析草稿的 `dev` 上依次集成 #67、#68、#72、#74 和 #76。浏览器同时检查草稿首发只建一个会话和两次重连提示。服务端保留对云端访客隐藏模型名的行为，建表覆盖解析草稿与旧会话模型偏好两张表。
