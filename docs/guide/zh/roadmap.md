# 说出一个名字，列出 TA 出场的每一秒

这是我们接下来想做的：在整部作品里，Seekino 不只找到一个画面，而是列出某个角色出现过的每一段和对应时间，一段不漏。

## 计划中

- **人物出场全量列举** — 说出一个角色，列出 TA 在整部作品里出现的每一段。
- **Cloud 个人资料库** — 登录后直接在 Cloud 上传、解析自己的视频，不用自己部署。
- **剪辑参考复用** — 记住解析过的运镜和动效，让 Agent 下次剪辑直接用上。

这些都还没有排期。你最想先要哪一个？来交流群告诉我们，你的意见可能直接影响我们先做哪一个。
