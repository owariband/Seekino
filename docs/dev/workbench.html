Seekino/管理工作台

概览

门槛状态来自已有验收报告；卡片状态、PR 合并或关闭都不自动代表验收通过。历史完成项保留原验收范围。

工作台使用说明

三个视图，同一份数据

概览回答“当前里程碑能否交付、卡在哪里、先做什么”；看板按分类展示全部卡片；验收门槛逐条列出用例结果和证据。三者读取同一份仓库数据。

闭环地图

按用户实际经过的顺序排列阶段。阶段状态由其门槛汇总：任一门槛未通过即为未通过，全部通过才算通过，其余为待测。阶段右侧是挡在它前面的工作卡。

四种状态

TODO 尚未推进；PROGRESSING 正在实施；VERIFYING 实现或交付已完成、验收未完成；DONE 在约定范围内已验收。PR 合并、测试通过都只支持对应阶段，不能直接记为 DONE。

状态一致性

页面会列出“DONE 却仍带待核对、待验收、Draft 等标签”的卡片，以及缺少截止日的 P0 卡。这些只是提醒，页面不会自动改状态；核对后告诉 Agent 更新。

项目统一维护

新增工作、调整状态、补充门槛结果时直接告诉 Agent，由 Agent 更新仓库中的 docs/dev/workbench.html。页面不编辑、不保存，也不读取浏览器草稿；刷新即可看到最新内容。

数据有采集日期

这是离线页面，PR、课程进度与费用不会自动联网刷新；每项都标注采集时间。未知的数值显示为“未知”，不按 0 计算。
