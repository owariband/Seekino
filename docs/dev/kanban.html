使用与维护说明

看板使用说明

同一份数据，三种卡片

模块描述有范围的现有能力；需求描述希望达成的结果；任务描述具体交付。分类用于归属，关联卡片用于连接上下游。

始终只有三列

TODO 是尚未推进的工作，PROGRESSING 是正在实施或验收的工作，DONE 是在约定范围内完成的工作。已搁置、待核对、待验收作为标签保留。点击卡片可查看工作范围、下一步和相关资料。

项目统一维护

这是项目共用的看板。新增工作、调整状态或补充资料时，直接告诉 Agent，由 Agent 更新仓库中的 docs/dev/kanban.html。项目文件更新后刷新页面，即可查看最新内容。

历史证据继续保留

当前卡片状态在本看板维护；problems.md 保存问题分析和历史事实，devlog.md 保存决策、实验及效果。历史 DONE 沿用原范围，本次整理没有重新执行这些业务验收。

数据有采集日期

这是离线看板，PR 与分支信息不会自动联网刷新。更新时读取新的证据，补充卡片和采集日期。PR 合并、关闭或本地分支存在，都不能单独证明任务已完成。
