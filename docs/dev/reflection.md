收益是需要量化的
你如何评估你新的tool的改动是否有效？
你要看tokens消耗，agent调用tool出错的频次下降，你要看tool整体耗时或者从context返回的角度为agent带来的收益

这些量化的指标收益，综合的指标收益，才是我们的评估依据啊

你只看到你解决了一个指标，没看到另一个指标上升了，这怎么能行？
